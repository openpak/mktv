About this site

OpenKart is OpenPak's own site for Mario Kart 8 on Wii U. It reads what the game uploaded to OpenPak's Mario Kart 8 server and shows it: Mario Kart TV highlights, time-trial ghosts, the ranking for each course, and community tournaments.

What it cannot show

  • Replays. A highlight (the game's Mario Kart TV recording) is a recording the game replays with its own engine. Nothing outside the game can play it, so the site shows the details and thumbnail the game uploads with it, and a video if the player published one.
  • Ghosts. Ghost files can be downloaded but only play in the game.
  • Names. Players appear by player ID for now.

Source

Written for OpenPak, AGPL-3.0-only: github.com/openpak/mktv. It was written from public protocol documentation (NintendoClients by Kinnay, MIT) and shares no code with any other Mario Kart TV site.
